# ASF-PostComment

Плагин для **[ArchiSteamFarm](https://github.com/JustArchiNET/ArchiSteamFarm)**, который добавляет чат-команду `POSTCOMMENT` — вручную оставить комментарий на стене любого Steam-профиля от имени одного или нескольких ботов.

В отличие от остальных плагинов серии (которые работают в фоне сами по себе), это **ручная команда**, которую оператор вводит явно, когда нужно — своей рассылки/расписания у неё нет.

## Команда

```
POSTCOMMENT <bots> <steamID> <text>
```

- `<bots>` — селектор ботов, тот же синтаксис, что и у обычных команд ASF: имя одного бота, список через запятую, `ASF`/`@ALL` (все боты этого инстанса), `@ONLINE`/`@OFFLINE`/`@FARMING`/`@IDLE`, диапазоны (`bot1..bot5`) и т.д.
- `<steamID>` — SteamID64 (числовой, например `76561198000000000`) профиля, на стене которого оставить комментарий. Должен быть индивидуальным аккаунтом (не группа/анонимный аккаунт).
- `<text>` — текст комментария, всё до конца строки (пробелы и пунктуация внутри сохраняются как есть). Ограничение — 255 символов, как у самого Steam.

Пример — оставить один и тот же комментарий от лица всех ботов инстанса:

```
POSTCOMMENT ASF 76561198000000000 gg, nice profile!
```

Каждый указанный бот пытается оставить комментарий независимо и параллельно (как и большинство команд самого ASF, оперирующих несколькими ботами разом) — в ответе будет по одной строке на каждого бота с результатом (`Posted a comment...` / `Failed to post the comment.` / `Not connected!`).

Требуется доступ не ниже `Master` — считается per-bot (через тот же механизм проксирования доступа `GetProxyAccess`, что и у встроенных команд ASF: если вы работаете от имени пользователя с ограниченным доступом на конкретном боте, команда сработает только на тех ботах, где у вас реально есть `Master`+).

## Установка

1. Скачайте архив плагина из [Releases](../../releases) и распакуйте в папку `plugins` рядом с ASF (создайте подпапку с именем плагина).
2. Перезапустите ASF.

## Конфигурация

Единственная настройка — глобальный вкл/выкл, в `ASF.json`, как дополнительное (нераспознанное ASF) свойство верхнего уровня:

```json
{
	"PostCommentEnabled": true
}
```

| Свойство | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `PostCommentEnabled` | `bool` | `false` | Включает/выключает команду `POSTCOMMENT`. Пока выключено, ASF ведёт себя так, будто плагина нет вообще (команда не распознаётся). |

## Сборка

Проект использует **[ASF-PluginTemplate](https://github.com/JustArchiNET/ASF-PluginTemplate)** и собирается вместе с исходниками ASF, подключёнными как git submodule:

```sh
git clone --recurse-submodules https://github.com/buddymurdock/ASF-PostComment.git
cd ASF-PostComment
dotnet build -c Release
```

Если репозиторий уже склонирован без `--recurse-submodules`, подтяните submodule отдельно:

```sh
git submodule update --init --recursive
```
